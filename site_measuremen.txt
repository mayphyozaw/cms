Engineer Request	Site Measurement
Request for inspection/approval	Actual quantity measurement

. Engineer Request (ER)

Sometimes called:

Inspection Request
Work Inspection Request
Site Inspection Request
✅ Purpose

Contractor requests engineer/consultant to:

inspect completed work
approve work quality
verify work before next stage
✅ Example
Contractor completed slab reinforcement.

Now contractor sends:

Engineer Request:
"Please inspect slab reinforcement before concrete pouring."
✅ ER Contains

Usually:

- Project
- Request No
- Work Type
- Location
- Drawing Ref
- Date
- Status
- Requested By
- Approved By
✅ Workflow
Work Completed
    ↓
Engineer Request
    ↓
Inspection
    ↓
Approval / Rejection
🔷 2. Site Measurement
✅ Purpose

Measures:

actual executed quantity
dimensions
completed work amount

Used for:

progress claim
contractor payment
BOQ verification
✅ Example
Concrete Slab
Length = 5m
Width = 4m
Thickness = 0.15m
Formula

Volume=Length×Width×Height


🔷 Relationship Between Them

🔷 VERY IMPORTANT PROFESSIONAL CONCEPT
Site Measurement = “How much work?”
